## 5. 第二门：AI必要性与业务分工

- **状态**：`PASS`
- **证据状态**：`SUFFICIENT`
- **置信度**：中
- **一句话判断**：项目采用“规则预检和约束 + AI处理非结构化信息及生成 + 人工承担确认和发布责任”的合理混合分工。

### 流程与节点分工

| 节点 | 最适合方式 | 能力、权限与信息边界 | 判断依据 |
|---|---|---|---|
| Brief及必需文件完整性 | 规则 | 只判断可枚举条件 | 确定性强，无需AI |
| 枚举、单位、格式、长度、敏感词 | 规则 | 依据生效字段和合规规则 | 要求稳定、可审计 |
| 图片、Excel、PDF属性候选提取 | AI辅助 | 无来源不得补写材质、成分或功能；冲突转人工 | 输入非结构化且变化大 |
| 标题和卖点草稿 | AI辅助 | 只能引用已确认属性和生效品牌规范 | 属于受约束生成任务 |
| 低置信、资料冲突和规则失败 | 人工 | 由商品运营处理例外 | 错误后果需人工承担 |
| 属性确认、创意取舍、正式发布 | 人工 | AI无独立发布权限 | 明确责任和授权边界 |
| 价格、库存、促销 | 原系统及授权人员 | 完全排除AI | 不属于本次问题范围 |

### 目标流程

`资料规则预检 → AI提取候选属性及出处 → 基于确认事实生成文案 → 规则校验 → 人工逐项确认/修改 → 确认后写入PIM → 原有抽查`

- **AI候选节点**：非结构化资料提取；受品牌与事实约束的标题、卖点生成。
- **规则节点**：完整性、枚举、单位、格式、长度、敏感词和禁止宣称。
- **人工决策点**：来源冲突、低置信、规则失败、创意取舍、最终确认和发布。
- **退出条件**：AI或检索不可用时隐藏AI草稿，恢复原人工流程。
- **一票否决**：未触发。AI没有获得零容错或无授权的最终决定权。
- **限制**：材料未提供成熟SaaS、OCR/RPA或纯流程优化的同口径经济对比；这不阻止小流量试点，但扩量前应补做自研/采购/非AI方案比较。

## 10. 决策合成

- **最终决策**：`GO / 应该做`
- **决定性规则**：申请进入试点所要求的真需求、业务分工、端到端POC与集成、限额投资、运营兜底五道门均为 `PASS`，且没有适用的一票否决。
- **决定性证据**：E01–E12。
- **为什么不是 `VALIDATE-FIRST`**：仍需验证的在线采用率、业务兑现率和规模ROI，正是获批试点要取得的证据；在进入试点前，没有另一项会改变安全边界或试点可行性的关键验证需要先行完成。
- **为什么不是 `NO-GO`**：不存在已验证的需求、AI分工、技术、预算或运营致命障碍；组合A也没有低于预冻结停止阈值。

## 12. 范围限制与复评条件

- **本结论不覆盖**：自动发布、全量上线、其他品牌或人群、多语言、多平台、价格库存促销、任何更高自动化等级。
- **仍未知但不改变本次结论**：真实在线采用率、外包减少量、业务兑现率、完整规模化TCO、规模ROI及回收期。
